What the EUPEX catalogue owns

The catalogue owns the component metadata, classification and integration status. Source code remains in the maintainer’s repository. An EasyBuild recipe may live alongside the source under easybuild/, while a validated copy can be contributed to the central EasyBuild or EESSI workflow.
